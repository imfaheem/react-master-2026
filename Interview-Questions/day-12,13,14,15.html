What is rendering in React? Rendering is the process where React executes a component function to produce a new description of the UI (React elements). It does not automatically mean the DOM is updated. Does every render update the DOM? No. Every render executes the component again, but React updates the DOM only if the rendered output differs from the previous one. What is the difference between the Render Phase and the Commit Phase? Render Phase: React executes components and prepares the next UI tree.
Commit Phase: React applies the necessary changes to the real DOM and the browser displays them. What is React.memo? React.memo is actually a performance optimization technique for functional components. It prevents unnecessary re-renders by comparing the component's previous props and new props. If the props are unchanged, React skips rendering that component.
OR
React.memo is a Higher-Order Component (HOC) that memoizes a function component. If the component receives the same props as the previous render, React reuses the previous result instead of executing the component again. What is useCallback? useCallback is a React Hook that memoizes a function reference. When its dependencies remain unchanged, useCallback returns the same function reference from the previous render instead of creating a new function reference. What is the function of dependency array in useCallback Hook? The dependency array in useCallback tracks the values used by the callback. When those dependencies do not change, useCallback keeps the same function reference. When any dependency changes, it provides a new function reference. What if the dependency array is empty [] in useCallback? It means that there is no changing dependencies inside the Callback function. What is useMemo hook? useMemo is a React Hook that stores the value returned by a callback function and reuses the previously stored value on future re-renders when its dependencies remain unchanged. Why do we need useMemo hook? We need `useMemo` to avoid unnecessary recalculations and improve performance. It is especially useful when a calculation is expensive or when a computed value needs to keep the same reference between re-renders. What is the function of dependency array in useMemo Hook? The dependency array in useMemo tracks the values that the callback function depends on. If the dependencies remain unchanged, useMemo reuses the previously stored value. If any dependency changes, useMemo executes the callback function again and stores its new returned value. Difference between useMemo and useCallback? useMemo: It memoizes the result of a callback function and returns the memoized value, which can be a single value, an array, or an object. The memoized result can be passed to a child component through props and may help skip unnecessary re-renders if the child component is wrapped with React.memo.
useCallback: It memoizes the function reference itself and returns the memoized function reference, not the result returned by the function. If the function reference is passed to a child component through props, the child component may skip unnecessary re-renders if it is wrapped with React.memo.
