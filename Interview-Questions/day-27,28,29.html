What is Redux? Redux is a predictable state management library used to manage and centralize application state. What is Redux Store? Redux Store is the central JavaScript container that holds the application's global state. It allows reading the state and handles state changes through reducers. What is Reducer? A Reducer is a pure function that takes the current state and an action as arguments, and returns a new state object without mutating the original state. What is Action? An Action is an object that describes what happened or what change should occur in the application state.
