What are CSS Modules?

CSS Modules are a CSS styling approach in which CSS class names are locally scoped to a component. They prevent global class-name conflicts by generating unique class names during the build process.

What is SCSS?

SCSS is a CSS preprocessor syntax that extends CSS with features such as variables, nesting, mixins, functions, and reusable styles.

Difference between SCSS vs CSS Modules?

SCSS enhances CSS syntax and provides features for maintainability, while CSS Modules provide local scoping for CSS classes. They can also be used together.

What is a mixin?

A mixin is a reusable block of SCSS styles that can optionally accept parameters.

What is @extend?

@extend allows one selector to share styles with another selector by combining selectors in the generated CSS.

What is Styled Components in React?

Styled Components is a CSS-in-JS library that allows us to create styled React components using tagged template literals. It generates unique class names for styled components, helping avoid traditional global class-name conflicts.

What is CSS-in-JS?

CSS-in-JS is a styling approach where CSS styles are defined and managed using JavaScript or TypeScript, often through a dedicated library.

What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework that provides low-level utility classes for building custom user interfaces directly in markup.

What does utility-first mean?

Instead of creating custom CSS classes for every component, we compose small utility classes such as flex, p-4, text-center, and bg-blue-600 to build.

What is mobile-first design?

Mobile-first design means we start with styles for smaller screens and progressively enhance the layout for larger screens using responsive breakpoints.

How does Tailwind handle responsive design?

Tailwind uses responsive prefixes such as sm:, md:, lg:, xl:, and 2xl: to apply utilities at specific minimum viewport widths.
