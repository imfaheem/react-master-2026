What is rendering in React? Rendering is the process where React executes a component function to produce a new description of the UI (React elements). It does not automatically mean the DOM is updated. Does every render update the DOM? No. Every render executes the component again, but React updates the DOM only if the rendered output differs from the previous one. What is the difference between the Render Phase and the Commit Phase? Render Phase: React executes components and prepares the next UI tree.
Commit Phase: React applies the necessary changes to the real DOM and the browser displays them. What is React.memo? React.memo is actually a performance optimization technique for functional components. It prevents unnecessary re-renders by comparing the component's previous and new props. If the props are unchanged, React skips rendering that component.
OR
React.memo is a Higher-Order Component (HOC) that memoizes a function component. If the component receives the same props as the previous render, React reuses the previous result instead of executing the component again.
