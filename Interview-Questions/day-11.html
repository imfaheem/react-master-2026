What is Data Fetching?

Data fetching is a process of requesting data from another source, usually a server or API, and using that data inside the application.

What is a Server?

A Server is a computer or an application program that receives requests, processes them, and sends back responses.

What is an API?

An API (Application Programming Interface) is a communication interface that allows different software applications to exchange data.
In web development, a React frontend sends requests to an API, and the API communicates with the backend and database, then returns data, usually in JSON format.
APIs also enforce security, validation, and business rules, preventing the frontend from accessing the database directly.

What is REST API?

A REST (Representational State Transfer) API is a type of web API that follows a set of architectural principles and constraints for communication between a client and a server.
It typically uses HTTP methods such as GET, POST, PUT, and DELETE to perform CRUD operations and usually exchanges data in JSON format.

What is a Request?

A Request is simply a message sent from the client (React app) to the server asking it to perform some action such as fetch, add, delete or update etc.

What is a Response?

A Response is the message sent back by the server after processing the client's request. It contains the requested data, a success or error status, and other relevant information.

What is JSON?

JSON (JavaScript Object Notation) is a lightweight, language-independent format used to exchange structured data between applications.
React applications commonly receive API data in JSON format and convert it into JavaScript objects or arrays using response.json().

Why do we need a loading state?

A loading state is used to inform the user that the application is currently fetching data from the server. During this time, the request is in progress (or pending).
Instead of showing a blank screen, we display a loading indicator to improve the user experience.

Why do we need an error state?

An Error state is used to handle API failures, such as network issues, server errors, or an invalid API endpoint.
Instead of crashing or displaying a blank screen, the application displays a meaningful error message so that users understand what went wrong.

Why do we use AbortController?

We use AbortController to cancel an in-progress API request when it's no longer needed, such as when a component unmounts, helping prevent memory leaks and unwanted state updates.
