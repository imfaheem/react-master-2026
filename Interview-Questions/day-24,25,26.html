What is Axios?

Axios is an open-source HTTP client library for JavaScript. It is used to connect the frontend application with the backend/API to perform HTTP requests.
Such as GET, POST, PUT, PATCH, and DELETE.

HTTP Methods:

GET: Retrieves data from a server without altering the server state.
POST: Sends data to a server to create a new resource or entry in the database.
PUT: Completely replaces an existing resource on the server with a new payload.
PATCH: Applies partial updates to an existing resource, modifying only the specified fields.
DELETE: Removes a specified resource or entry from the server.

Difference between PUT and PATCH?

PUT is used to completely replace an existing resource on the server, requiring you to send the full updated payload of data. Whereas PATCH is used for partial updates, allowing you to send only the specific fields you want to modify.
In practice, omitting a field in a PUT request can cause that missing data to be overwritten or wiped on the server, while a PATCH request leaves all unmentioned fields untouched—making PATCH ideal for lightweight, targeted edits.
PUT best suited for complete resource replacements or resets.

Difference between fetch() and axios()?

  • fetch is a native browser API, while axios is an external library that requires installation.
  • fetch requires an extra manual step for data parsing from JSON. i.e. await res.json(). While axios automatically parses JSON responses. i.e. response.data
  • fetch does not reject on 404 or 500 errors unless checked manually via res.ok. While axios automatically rejects promises on HTTP error status codes (4xx and 5xx) and jumps to .catch()
  • axios supports built-in request/response interceptors (ideal for attached JWT tokens), upload/download progress tracking, and request cancellation out-of-the-box.

What is API Layer?

API Layer is a separate part of an application responsible for handling communication with backend APIs, including making requests, processing responses, and handling API-related errors, so that API logic remains separate from UI components.

What are Environment variables?

Environment variables are configuration values stored outside the application code that allow different settings, such as API URLs, to be used for different environments without changing the source code.

What is Authentication?

Authentication is the process of verifying the identity of a user or a system. It determines who the user is, usually by using credentials such as username/password, OTP, biometrics, or tokens.

What is Authorization?

Authorization is the process of determining what an authenticated user, system, or service is allowed to access or perform. It defines the permissions and access levels of a user, system or a service.

What are Authentication APIs?

Authentication APIs are backend API endpoints used to handle user identity and authentication-related operations such as registration, login, logout, token generation, token refresh, and password management.

What is JWT?

JWT (JSON Web Token) is an access token generated and signed by the server after successful authentication, which the client uses to access protected resources.

What is JWT format?

A JWT basically consist of 3 parts, seperated by dots (.)

  • 1. Header: That contains the information about the JWT, such as the signing Algorithm and Token type.
  • 2. Payload: That actually contains the claims, which are pieces of information carried by the JWT, such as user ID, role, or other relevant data.
  • 3. Signature: The Signature is used to verify the integrity and authenticity of the JWT and to detect whether the token has been tampered with or modified.

What is Protected Request?

A Protected Request is a combination of an API request and a JWT/Access Token that the client sends to the server to access a protected resource.

What is Access Token?

An Access Token is a credential issued by the server after successful authentication, which the client uses to access protected resources. It is commonly represented in JWT format.

What is Refresh Token?

A Refresh Token is a credential used by the client to request a new access token from the server after the current access token expires.

What is an Interpector?

An Axios Interceptor is a mechanism that allows us to inspect, modify, or handle HTTP requests and responses before they are processed by the application.

What is the Differance between Request Interceptor and Response Interceptor?

A Request Interceptor handles or modifies a request before it is sent to the server.
A Response Interceptor handles or modifies a response after it is received from the server, including successful responses and errors.
