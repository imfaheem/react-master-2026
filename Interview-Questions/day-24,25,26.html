What is Axios? Axios is an open-source HTTP client library for JavaScript. It is used to connect the frontend application with the backend/API to perform HTTP requests. Such as GET, POST, PUT, PATCH, and DELETE. HTTP Methods: GET: Retrieves data from a server without altering the server state. POST: Sends data to a server to create a new resource or entry in the database. PUT: Completely replaces an existing resource on the server with a new payload. PATCH: Applies partial updates to an existing resource, modifying only the specified fields. DELETE: Removes a specified resource or entry from the server. Difference between PUT and PATCH? PUT is used to completely replace an existing resource on the server, requiring you to send the full updated payload of data. Whereas PATCH is used for partial updates, allowing you to send only the specific fields you want to modify.
In practice, omitting a field in a PUT request can cause that missing data to be overwritten or wiped on the server, while a PATCH request leaves all unmentioned fields untouched—making PATCH ideal for lightweight, targeted edits. PUT best suited for complete resource replacements or resets. Difference between fetch() and axios()?
  • fetch is a native browser API, while axios is an external library that requires installation.
  • fetch requires an extra manual step for data parsing from JSON. i.e. await res.json(). While axios automatically parses JSON responses. i.e. response.data
  • fetch does not reject on 404 or 500 errors unless checked manually via res.ok. While axios automatically rejects promises on HTTP error status codes (4xx and 5xx) and jumps to .catch()
  • axios supports built-in request/response interceptors (ideal for attached JWT tokens), upload/download progress tracking, and request cancellation out-of-the-box.
What is API Layer? API Layer is a separate part of an application responsible for handling communication with backend APIs, including making requests, processing responses, and handling API-related errors, so that API logic remains separate from UI components. What are Environment variables? Environment variables are configuration values stored outside the application code that allow different settings, such as API URLs, to be used for different environments without changing the source code.
