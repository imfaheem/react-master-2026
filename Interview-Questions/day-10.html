What is useRef Hook?

useRef is a React Hook that stores and remembers a mutable value that survives across multiple renders, without re-rendering the component when the value changes.

Why do we use to 'useRef' Hook?

We use useRef to store or remember a mutable value that survives across re-renders, without causing the component to re-render when that value is updated.

What does useRef return?

It returns an object with a single property. i.e. { current: initialValue }

What is ContextAPI?

Context API is a React feature that allows us to share data between components without passing props manually through every intermediate component through prop drilling.

What is createContext?

createContext is a special type of React function that returns an object i.e. Context that contains 2 properties.
1. Context Provider (Provider) and 2. useContext (Comsumer)

What is Context Provider?

A Context Provider is a React component that provides a value to all of its descendant components within the same Context. In simple words, it shares data with all the components inside it.

What is useContext Hook?

useContext is a React Hook that allows a component to access the values of a Context provided by the Context Provider without passing props manually through every level of the component tree.

Why was Context API introduced?

Context API was introduced to avoid prop drilling by allowing data to be shared directly with deeply nested components without passing props through every intermediate component.
